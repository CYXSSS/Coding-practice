# Coding Practice

算法与数据结构练习代码，按学期组织。

## 目录结构

```
├── 25fall/          # 基础算法练习
│   ├── 递归/        # 汉诺塔、斐波那契、迷宫、正则匹配等
│   ├── 数组/        # 两数之和
│   ├── 字符串/      # 字符串转换、大小写处理
│   ├── 滑动窗口/    # 最长子串、DNA 序列
│   ├── 其他/        # 素数、中位数、天数差
│   └── Alien_Invasion/  # Pygame 外星人入侵小游戏
├── 26spring/        # 数据结构实现
│   ├── Hash/        # 哈希表
│   ├── Linked_list/ # 单链表 / 双向链表
│   ├── Queue/       # 队列
│   ├── Stack/       # 栈（DFS、迷宫回溯、括号匹配、最长有效括号）
│   ├── Sorting/     # 冒泡、选择、插入、归并、快排、计数、二分查找
│   ├── String/      # 字符串压缩、Top-K、字符串匹配（BF / KMP / BM）
│   └── Tree/        # 二叉树遍历、BST、AVL、B 树、B+ 树、哈夫曼编码、堆
├── L04Project/      # 课程项目
└── test.py          # 临时测试
```

## 运行环境

- Python 3.x
- 部分内容依赖 Pygame（Alien_Invasion）
